What is happening?

Before transmission

The sender splits a message into packets. Each packet has a sequence number so the receiver can identify its place in the original message.

Remember

Packet switching sends data in separate packets. Routers forward packets towards the destination.

Arrival order vs sequence order

The receiver can get packets in a different order from the order they were sent. Sequence numbers help it put the data back in order.

Question: Why might packet 3 arrive before packet 2?
Show a model answer

Packets can travel along different routes through the network. A route may be shorter or less congested, so a later packet can arrive before an earlier packet. Sequence numbers help the receiver reassemble the message in the correct order.

This is a simplified educational model. Real routing decisions and packet fields depend on network protocols; packet switching does not mean every packet must take a different route.
